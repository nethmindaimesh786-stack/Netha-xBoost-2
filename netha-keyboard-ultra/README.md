# NETHA KEYBOARD ULTRA (Web Preview)

A standalone HTML/CSS/JavaScript keyboard interface based on the supplied NETHA KEYBOARD ULTRA design.

## Run
Open `index.html` in a modern mobile browser or serve this folder with any static web server.

## Included interactions
- QWERTY letter buttons, Shift, Backspace, Space, Enter, comma and period
- English / basic Sinhala phonetic mode toggle
- Basic number and symbol layer
- Key press popup preview and animated rainbow letter glyphs
- Emoji shortcuts and emoji picker panel
- Clipboard copy and an in-page saved clipboard list
- Uppercase/lowercase, clear text and decorative text styles
- QWERTY / AZERTY layout toggle
- Toolbar hide/show
- Voice typing when the browser supports the Web Speech Recognition API

## Notes
- The Sinhala transliteration table is a starter phonetic mapping, not a complete Sinhala language engine. Some spellings and conjuncts may need additional rules.
- Voice typing and system clipboard access depend on browser support and permissions.
- This is a browser-based keyboard demo. It is not an Android system-wide input method.
- The text output target remains hidden to preserve the supplied keyboard-only appearance.
