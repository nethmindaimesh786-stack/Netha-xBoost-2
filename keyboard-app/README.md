# NETHA KEYBOARD ULTRA

Native Android InputMethodService keyboard project. The keyboard can be enabled in Android Settings and used in other apps.

## Build
Open this folder as an Android Gradle project in Android Studio/AndroidIDE, or use the repository GitHub Actions workflow to build a debug APK.

## Enable
Install the APK → open NETHA KEYBOARD ULTRA → tap **Enable keyboard** → enable it in Android settings → choose NETHA KEYBOARD ULTRA as the current keyboard.

## Notes
- The original HTML keyboard's visual layout and feature ideas are being recreated with native Android views so it can type into other apps.
- Sinhala phonetic conversion is a built-in rule/dictionary engine and will be expanded with real-device testing.
- Voice input uses the Android input method's voice input intent where supported.
